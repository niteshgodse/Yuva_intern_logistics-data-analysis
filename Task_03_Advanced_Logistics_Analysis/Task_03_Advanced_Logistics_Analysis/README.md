# Task 03 – Advanced Data Analysis and Visualization in Logistics

## Objective
This task deepens logistics analytics skills by using a simulated shipment dataset to explore operational performance, delivery reliability, shipment volume, transportation cost, and relationships among key metrics.

## Deliverables
- `Advanced_Logistics_Analysis.ipynb` – complete, executable Python analysis including reproducible data simulation
- `advanced_logistics_analysis.py` – Python script used for analysis and visualizations
- `pseudocode.txt` – analysis workflow
- `Advanced_Logistics_Analysis_Report.docx` – documented methodology, visualizations, interpretations, code excerpts, findings, and recommendations
- `data/advanced_logistics_dataset.csv` – generated simulated dataset
- `charts/` – visualization outputs

## Tools
Python, Pandas, NumPy, Matplotlib, Jupyter Notebook.

## Main Analysis
The project includes data simulation, data validation, descriptive statistics, KPI calculation, distribution analysis, time trends, cost comparisons, regional service analysis, relationship analysis, correlation analysis, operational insights, and recommendations.

The notebook uses a fixed random seed so that the hypothetical dataset can be reproduced consistently.
